# CampusXchange

### Student Marketplace for Indian College Campuses

CampusXchange is a web-based student marketplace designed for college campuses in India. It helps students buy, sell, and exchange useful second-hand items within their campus community.

Students can create listings with photos, prices, and condition details, while other students can browse, search, filter items, and contact sellers directly.

**🌐 [Live Demo](https://campusxchange.campusxchange.workers.dev/)** | **💻 [GitHub Repository](https://github.com/shalinishahani/CampusXchange)**

## ✨ Features

- 🔐 Student registration and login
- 📦 Create and manage product listings
- 🔎 Search and filter listings
- 🏷️ Product categories and condition details
- ❤️ Wishlist functionality
- 👤 Student profile management
- 📊 Personal dashboard
- 📋 Manage your own listings
- 📧 Contact sellers through email
- 📱 Responsive design for desktop and mobile devices

## 🛒 What Students Can Sell

Examples include:

- Textbooks and study materials

- Electronics
- Bicycles
- Hostel supplies
- Furniture
- Other useful campus items

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript
- **Framework:** TanStack Start and TanStack Router
- **Styling:** Tailwind CSS
- **Backend and Database:** Supabase and PostgreSQL
- **Authentication:** Supabase Auth
- **Deployment:** Cloudflare Workers
- **Tools:** Git, GitHub, VS Code

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/shalinishahani/CampusXchange.git
cd CampusXchange
```

**2. Install dependencies**

```bash
npm install
```

**3. Configure environment variables**

Create a local `.env` file using `.env.example`, if available, and add the required Supabase configuration. Never commit your `.env` file or secret keys to GitHub.

**4. Start the development server**

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

## 🎯 Project Goal

CampusXchange aims to make buying and selling second-hand items easier for college students through a marketplace focused on campus communities.

Instead of relying only on general marketplaces, students can discover useful items from fellow students and contact sellers directly.
